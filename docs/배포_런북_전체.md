# Eternal Beam 전체 배포 런북

문서 `이터널빔 임베디드.hwp` 기준, **임베디드 조립 완료 + 유니티 영상 생성 완료**를
전제로 한 "처음부터 배포까지" 순서입니다. 4개 구성요소를 각각 배포합니다.

| 구성요소 | 역할 | 배포 위치 | 상태 |
|---|---|---|---|
| 소비자 웹앱 (이 저장소 `src/`) | 사진 업로드 → 누끼/3D → 클라우드 전송 | **Vercel** | 빌드 ✅ |
| 합성/누끼 백엔드 (`backend/`) | FastAPI + FFmpeg + rembg | **Render** | `render.yaml` ✅ |
| 라즈베리파이 센서 (`python/eternal_beam_pi.py`) | ToF+NFC+마이크 → UDP | **기기 내 systemd** | 자동실행 ✅ |
| 유니티 앱 (`EternalBeam/`) | UDP 수신 → 영상 연출 | 기계 속 폰 | (완료 가정) |

데이터 경로
- 소비자폰 ↔ 기계폰: **인터넷(Supabase)** — 사진/3D영상/배경선택
- 라즈베리파이 → 기계폰: **Wi-Fi UDP** — `{"event":"approach"}`, `{"event":"nfc_tagged","theme_id":...}`, `{"event":"voice"}`

---

## 1) 백엔드 → Render

1. Supabase SQL 실행: `docs/supabase_hybrid_business.sql`, `supabase_payment_iap.sql`, `supabase_subscription.sql`
2. Render → **New → Blueprint** → 이 repo의 `render.yaml` **Apply**
3. Environment 탭에 직접 입력: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `LUMA_API_KEY`
4. 확인: `GET https://eternal-beam-video-api.onrender.com/health` → `{"status":"ok"}`

상세: `DEPLOY.md`, `docs/RENDER_설정_가이드.md`

## 2) 소비자 웹앱 → Vercel

1. Vercel **New Project** → 이 repo 연결 (Framework: Vite 자동인식)
2. Build `npm run build`, Output `dist` (루트 `vercel.json`이 `/api`를 Render로 프록시)
3. **Settings → Environment Variables** 에 `.env.example` 기준 `VITE_*` 입력
   - `VITE_VIDEO_API_URL` = `https://eternal-beam-video-api.onrender.com` (끝 슬래시 없이)
   - `VITE_FIREBASE_*`, `VITE_SUPABASE_*`, `VITE_TOSS_*`
   - ⚠️ `.env.vercel.prod` 파일은 **gitignore 처리됨** — Vercel UI에만 값 입력, 커밋 금지
4. Deploy → 빌드 확인 (로컬 `npm run build` 통과 확인됨)

## 3) 라즈베리파이 센서 브리지 → systemd 자동 실행

> 조립 완료 가정. 기기 전원만 켜면 자동 시작/복구되도록 설치.

```bash
cd ~/eternal-beam-app
sudo apt install -y python3-pip portaudio19-dev alsa-utils i2c-tools
pip install -r python/requirements-pi.txt

cp python/systemd/eternal-beam-pi.env.example python/systemd/eternal-beam-pi.env
nano python/systemd/eternal-beam-pi.env      # UDP_HOST=기계폰 Wi-Fi IP

sudo bash python/systemd/install.sh
journalctl -u eternal-beam-pi.service -f      # UDP 전송 로그 확인
```

- NFC 카드 ↔ 테마 매핑: `python/nfc_theme_map.json` (UID hex → theme_id) 편집
- PC에서 배선 없이 점검: `python python/eternal_beam_pi.py --simulate`
- 상세/배선: `python/systemd/README.md`, `docs/INMP441_PI_SETUP.md`

## 4) 유니티 앱 (완료 가정)

- `UDPReceiver` 포트 **5005** 수신 → `approach/voice/nfc_tagged/nfc_match` 처리
- 라즈베리파이 `eternal_beam_pi.py`가 보내는 JSON 계약과 일치함 (검증 완료)

---

## 배포 후 엔드투엔드 점검

1. `GET /health` (Render) → ok
2. 웹앱에서 사진 업로드 → 누끼/테마 선택 → 기기 전송
3. 기기 폰(Unity) 로그에서 콘텐츠 수신 확인
4. 손 접근 → `approach`, NFC 태깅 → 배경 전환, 말하기 → action 영상 재생 확인

배포 전 체크: `docs/배포_전_체크리스트.md`
